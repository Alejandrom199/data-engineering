## What is this?

This repository is a course remote registry for [OpenLearn](https://github.com/alenj0x1/open-learn). Any OpenLearn instance can add this registry to install and run the **Mentor de Ingeniería de Datos (Nivel 0 → Experto)** course.

## Install a course on your instance

1. Sign in to your OpenLearn instance as an **administrator**.
2. Go to **Cursos → Explorar cursos**.
3. Add this registry URL as a remote:
   ```text
   https://github.com/Alejandrom199/data-engineering
   ```
4. Click **Instalar** on the Data Engineering course.
