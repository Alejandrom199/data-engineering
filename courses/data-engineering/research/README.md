# 🔬 Investigación y Metodología Pedagógica

Este directorio contiene las bases teóricas, fuentes de documentación oficial, plan de estudios estructurado y el syllabus formal del curso **Mentor de Ingeniería de Datos (Nivel 0 → Experto)**.

## Archivos

- **`sources.md`**: Referencias bibliográficas, libros fundamentales, papers académicos y documentación oficial de las tecnologías enseñadas.
- **`study-plan.md`**: Cronograma detallado semana a semana para completar el curso en un periodo de 9 a 12 meses dedicando entre 15 y 20 horas semanales.
- **`syllabus.json`**: Desglose estructurado de unidades, competencias, resultados de aprendizaje y criterios de evaluación.
